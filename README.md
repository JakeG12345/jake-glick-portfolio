# Jake Glick Build Museum

A Next.js portfolio site built from Jake's attached coding-history DOCX, public GitHub profile, live project captures, and local project notes/screenshots from `~/Desktop/Dev`.

## Run locally

```bash
npm install
npm run dev
```

The current dev preview is running at:

```bash
http://localhost:3017
```

## What is inside

- App Router Next.js 16 project with TypeScript
- Playable museum-style portfolio in `app/MuseumPortfolio.tsx`
- Global visual system in `app/globals.css`
- Project screenshots and icons in `public/projects`
- Featured projects: WhatsAppWrapped, Jashby, Car Lifestory, What The Puck, Moriah Jiu-Jitsu, Degree6, and HSC MC Maker
- Source log: attached DOCX, public GitHub metadata, live site screenshots, and safe local project captures
