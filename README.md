# Jake Glick Portfolio

A Next.js portfolio site built from Jake's public GitHub profile, public LinkedIn preview, and local project notes/screenshots from `~/Desktop/Dev`.

## Run locally

```bash
npm install
npm run dev
```

The current dev preview is running at:

```bash
http://localhost:3017
```

## What is inside

- App Router Next.js 16 project with TypeScript
- Custom single-page portfolio in `app/page.tsx`
- Global visual system in `app/globals.css`
- Project screenshots and icons in `public/projects`
- Featured projects: WhatsAppWrapped, Jashby/Daily Excel, Car Lifestory, HSC MC Maker, Degree6, and Moriah Jiu-Jitsu
