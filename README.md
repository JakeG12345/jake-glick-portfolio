# Jake Glick Portfolio City

A Next.js / Three.js portfolio site built from Jake's attached coding-history DOCX, public GitHub profile, live project captures, and local project notes/screenshots from `~/Desktop/Dev`.

## Run locally

```bash
npm install
npm run dev
```

The current dev preview is running at:

```bash
http://localhost:3017
```

## What is inside

- App Router Next.js 16 project with TypeScript
- 3D portfolio city in `app/MuseumPortfolio.tsx`
- Global visual system in `app/globals.css`
- Project screenshots and icons in `public/projects`
- 18 public GitHub repos represented
- 12 curated 3D map stops for the main projects, places, and experience landmarks
- 43 archive items represented below the map across shipped apps, prototypes, learning repos, and local training-ground folders
- Contact links surfaced in the fixed top ribbon and contact section
- Personal landscape details: Sydney harbour, Opera House-style sails, Harbour Bridge arch, Bondi Beach, Dover Heights home marker, football pitch, and gym landmark
- Location-tied stops for Blackbird / WhatsAppWrapped and Quantium work experience
- Source log: attached DOCX, public GitHub metadata, live site screenshots, and safe local project captures
